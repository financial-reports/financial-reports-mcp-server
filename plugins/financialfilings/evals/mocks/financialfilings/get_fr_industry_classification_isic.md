ISIC Rev.4 classes used by FinancialFilings. `companies_list?sub_industry=` takes
the 4-digit CLASS code.

| code | class name |
|---|---|
| 2710 | Manufacture of electric motors, generators, transformers and electricity distribution and control apparatus |
| 2811 | Manufacture of engines and turbines, except aircraft, vehicle and cycle engines |
| 2818 | Manufacture of power-driven hand tools |
| 2819 | Manufacture of other special-purpose machinery |
| 2821 | Manufacture of agricultural and forestry machinery |
| 3311 | Repair of fabricated metal products |

Section C covers manufacturing. ISIC is not GICS and not NAICS: a GICS or NAICS
industry does not map one-to-one onto a class here, so say the mapping is
approximate if the user asks in those terms.
